# mystery-books

## 54字の物語パズル コレクション

ちょうど54文字でできた、超短編パズルの作品集。
じょーかーとクマ（Muse）がチャットで出し合って遊んできた記録です。

### 読み方

- 各作品は盤面（グリッド）で表示されます。**右の列を、上から下へ**読むと物語になります。
- どの作品も本文はきっかり54文字です。

### シリーズ

- **ロジック編（#01〜#06）**：「犯人だけが嘘をついている」ルールで、犯人を当てる論理パズル。
- **ツイスト編（#07〜#13）**：最後まで読むと意味がひっくり返る、「意味がわかるとゾクゾクする」系。

### ファイル

- [stories.md](stories.md) — 全13作品（盤面・本文・問題）
- [answers.md](answers.md) — 答えと解説（ネタバレ注意。#13は挑戦中のため答え未掲載）
